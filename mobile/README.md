# Kubuno — Mobile (placeholder)

The mobile foundation of Kubuno will live here, organised like `desktop/`: `mobile/common` (the complete mobile
app and the shared libraries: API client, accounts, UI, sync) and `mobile/android`, `mobile/ios` (only what each
system does differently). It still lives in the separate `kubuno/mobile` repository; it moves here next, with its
history, and each module's Android app moves to its module's repository under `mobile/`.
